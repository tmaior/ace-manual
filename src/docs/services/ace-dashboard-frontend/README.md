# ace-dashboard-frontend

React/Vite frontend for the ACE (Automation, Control & Enablement) system.

## Purpose

- User-facing dashboard and management UI.
- Calls **ace-stack-backend** APIs (base URL from env, e.g. `VITE_API_URL`).
- Tech stack: React, TypeScript, Vite.

## Documentation

- **This folder**: Central reference for the service; detailed setup, API, and debugging stay in the service repo.
- **Repository docs**: In **ace-dashboard-frontend/docs/** (setup, development, deployment, architecture).
