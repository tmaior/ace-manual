# Start Here – ADRs

This directory holds **Architecture Decision Records (ADRs)** for ACE. Below is each file with a short description.

---

## Files

**[README.md](./README.md)**  
Overview of ADRs: what they are, how to add one, status values, and pointer to the list. Read this first if you are new to ADRs in this repo.

**[template.md](./template.md)**  
Template for new ADRs. Copy it, rename with a number and slug (e.g. `0001-use-nestjs-for-backend.md`), fill in Context, Decision, Consequences, and optionally Alternatives. Then add the new file to this index and START_HERE.

**[index.md](./index.md)**  
Plain list of all ADR files (links only). Update when you add or remove an ADR.
