# Main Rules - Non-Negotiable Principles

**Status**: These rules are MANDATORY for all ACE development work.

---

## Core Principles

### 1. English for Code and Documentation
- All code, comments, and documentation MUST be in English
- Variable names, function names, and file names must be English
- Git commit messages must be in English

### 2. Document Every Change
- Before writing code, read the existing documentation
- After making changes, update relevant documentation
- Every feature, fix, or change must be traceable

### 3. Never Invent — Read First
- Always consult documentation before implementing
- If documentation is missing, create it
- Never guess at requirements or patterns

### 4. Jira is the System of Record
- All development plans must be tracked in Jira
- Chat/Slack/Teams are NOT official documentation
- Reference Jira issues in commits and PRs

### 5. Explicit Approval Required
- Wait for explicit user approval before implementing
- Don't assume permission - ask and wait
- Document approvals in Jira

---

## Violation Policy

Violations of these rules may result in:
- Work being discarded
- Requiring rework
- Breaking audit trails
- Security or compliance issues
