## File Descriptions

### AI-AGENT-QUICKSTART.md
**Purpose**: High-visibility quick start guide for AI agents
**Contains**: 
- The 3 gates before code (Jira acceptance, user confirmation, PR review)
- Golden path flowchart
- What NOT to do (violations)
- Quick checklist

**When to read**: Before ANY development task

### FIRST-TIME-DEVELOPER.md
**Purpose**: Onboarding checklist for new developers
**Contains**: 
- Checklist of all required reading
- Key understanding questions
- Exception handling rules

**When to read**: First time working on ACE, or as refresher

### main-rules.md
**Purpose**: Core non-negotiable principles
**Contains**: 
- English for code/docs
- Document every change
- Never invent, read first
- Jira as system of record

**When to read**: First time, and as reminder

### jira-led-development-planning.md
**Purpose**: Define planning workflow using Jira
**Contains**: 
- Phase A-F workflow
- What NOT to do (prominent warnings)
- Human acceptance requirement
- Exception handling

**When to read**: Before any planning task

### ai-agent-ace-workflow.md
**Purpose**: AI agent-specific workflow
**Contains**: 
- Request reception
- Documentation review
- Planning phase
- Implementation phase
- Verification phase

**When to read**: For AI agents working on ACE
